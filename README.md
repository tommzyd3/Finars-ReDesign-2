# Finars ReDesign 2

Modern redesign of the **FIN ARS d.o.o.** website (www.finars.si).

## About

This is a complete redesign of the architectural bureau FIN ARS website, inspired by the elegant, minimalist design language of [Sato Interior Design](https://www.sato-interiordesign.com/).

### Design features
- Dark, sophisticated color palette with gold accent
- Elegant serif + clean sans-serif typography
- Full-screen hero section
- Responsive layout (desktop + mobile)
- Smooth scroll navigation
- Portfolio grid with hover effects
- Contact form

### Sections
1. **Hero** – Strong visual introduction
2. **O nas** – About the bureau + key stats
3. **Storitve** – Full list of architectural services
4. **Reference** – Project portfolio
5. **Ekipa** – Team presentation
6. **Kontakt** – Contact form + company details
